# WarmiMIND Web

This directory reserves the v2 frontend boundary for the source-grounded learning workspace.

During the transition, the current public Next.js demo remains at the repository root in `app/`, `components/`, and `lib/` so the baseline can continue to build while the v2 backend and data layers are introduced.

Future v2 web work should move or create learning-workspace UI here once the backend contracts are stable.
