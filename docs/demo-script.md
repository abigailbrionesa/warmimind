# Two-Minute Demo Script

## 0:00 - 0:20: Problem

"WarmiMIND helps students turn a dense STEM PDF into a structured study session. The goal is not generic chat; the goal is source-grounded learning."

## 0:20 - 0:45: Upload And Session

"A student uploads one PDF. The backend validates the file, creates a document record, extracts text, creates chunks, and starts a learning session."

## 0:45 - 1:15: Learning Workspace

"The workspace organizes the session into source chunks, summary, key concepts, guided questions, tutor chat, misconception checks, and next action. Each generated output is designed to point back to source chunks."

## 1:15 - 1:40: Misconception And Progress

"When the student answers a misconception check, WarmiMIND compares the answer with source evidence, identifies what is correct and missing, updates weak concepts, and recommends what to review next."

## 1:40 - 2:00: Evaluation

"The eval dashboard tracks retrieval hit rate, citation coverage, refusal behavior, question quality, and latency so the system can be measured instead of only demoed."
