# Public Project Summary

WarmiMIND is a source-grounded AI STEM learning workspace for uploaded PDFs. It turns one dense STEM document into a structured study session with document chunks, semantic retrieval, cited summaries, key concepts, guided questions, tutor chat, misconception checks, learning state, next recommended actions, and evaluation metrics.

The v2 rebuild focuses on credible AI product engineering: clear frontend/backend boundaries, FastAPI contracts, Supabase-ready migrations, pgvector retrieval, source-grounded generation, and measured quality. Quechua support is treated as experimental until reviewed by qualified speakers.
