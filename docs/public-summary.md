# Public Project Summary

WarmiMIND is a source-grounded AI STEM learning workspace for uploaded PDFs. It turns one dense text-based STEM document into a structured study session with inspectable document chunks, cited summaries, key concepts, guided questions, tutor chat, misconception checks, learning state, next recommended actions, and evaluation metrics.

The v2 MVP focuses on credible AI product engineering: clear frontend/backend boundaries, FastAPI contracts, Supabase-ready migrations, retrieval with refusal behavior, source-grounded outputs, Playwright-verified flows, and measured quality. Supabase persistence and raw PDF storage are optional; signed PDF URLs stay disabled by default until ownership and retention policies are complete. Quechua support is treated as experimental until reviewed by qualified speakers.
