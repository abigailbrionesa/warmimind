# ADR 0004: Use Source-Grounded Generation

## Status

Proposed

## Context

The product should help students learn from a specific PDF rather than provide generic AI answers.

## Decision

Generate summaries, concepts, guided questions, tutor answers, and misconception feedback from retrieved PDF evidence.

## Consequences

- Responses should include source references.
- Unsupported questions should trigger refusal or clarification behavior.
- Evaluation should measure citation coverage and refusal behavior.
