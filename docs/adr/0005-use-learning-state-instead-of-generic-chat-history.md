# ADR 0005: Use Learning State Instead Of Generic Chat History

## Status

Proposed

## Context

WarmiMIND v2 should structure learning, not only answer chat messages.

## Decision

Track concepts, questions answered, misconceptions, evidence references, weak areas, and next recommended actions as learning state.

## Consequences

- The app can guide students toward the next useful step.
- The MVP should avoid unsupported grades, mastery percentages, streaks, or leaderboards.
